## 3. Quarantined `RoomClient` (020 AC-8) — independent 4th review: block on exactly the two known findings

Confirmed: (F1) `reconnectAttempt` is reset in `handleOpen`, so a relay that accepts then closes (4408, hibernation churn, captive portal) keeps the client at ~500 ms retries forever — backoff defeated in the one case it exists for; (F2) `Math.round(baseDelay * (0.5 + random()))` yields 250 ms at `random() → 0`, under the normative 500 ms floor. Both fixes are three lines and disturb no existing expectation. AC-8's Given/When/Then has a real test (`drops, reopens, waits for replay, and flushes only disconnected intents`, `client.test.ts:221`). The architecture — replay gate, per-socket `lastSeen` reset, socket-identity guards, lane/gap-collapse queue, deliberate ack drop — is correct and matches the skill line by line. The defects survived three reviews because the backoff test never opens the reconnected socket and pins `random: () => 0.999`.

Recommendation to Maxx: authorize **one** targeted repair (T006c) limited to F1, F2, a `connect()` no-op when the URL is unchanged and the socket is healthy (060 will call it on every foreground), and the missing backoff test (open the reconnected socket, close without replay, `random: () => 0`). A rewrite is not warranted. Follow-ups filed separately: `onError` + close code on the connection callback (T017, 060 R3); `lastFrameAt === undefined` must read as NO LINK (030 R3 clarified). Every spec from 030 onward depends on this client; nothing in 030/040 can be leased until it integrates. The quarantine is untouched — the planner may not lease T006c without your explicit reversal recorded in the plan.
